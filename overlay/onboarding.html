Buffy 1.0

Your desk has a new coworker.

She’s already running. This quick setup connects her to your agents and shows where everything lives.

01

She’s already awake

Use the Buffy tray icon to show or hide her, move her to a corner, change her outfit, or open this guide again. Her window stays above other apps.

02

Connect Claude Code

From the Buffy checkout, install the hooks once. Then use /buffy inside Claude Code whenever you want to call her.

buffy install claude
03

Connect Freebuff

Add the best-effort instructions to a project’s AGENTS.md. The repo watcher still catches edits even when Freebuff ignores them.

buffy install freebuff
Installer or checkout?

The desktop installer includes the pet and her local daemon. The buffy commands for Claude and Freebuff run from this Node checkout. Run npm install and npm link there if buffy is not on your PATH.
