Buffy

Your desk has a new coworker.

She’s already running. This quick setup connects her to your agents and shows where everything lives.

01

She’s already awake

Use the tray icon to show or hide her, open settings, or quit. Press your summon shortcut to bring her forward, then write a prompt and hand it to Claude without leaving what you were doing.

02

Connect your agents

Open Settings → Connection and choose Connect for Claude Code, Gemini CLI, or Cursor. Packaged Buffy installs her own per-agent launchers, so no Node checkout is needed. Existing settings are backed up and can be removed from the same panel.

03

Connect Freebuff

Freebuff sessions are inferred from project activity with no setup. For explicit events, add the optional instructions from a checkout with buffy install freebuff.

Already have a checkout?

The desktop installer includes Buffy, the daemon, and the packaged agent setup. The buffy CLI and optional Freebuff instructions still run from the Node checkout — run npm install and npm link there if buffy is not on your PATH.
